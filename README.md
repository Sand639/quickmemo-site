# くいっくメモ（quickmemo-site）

iPhone アプリ「くいっくメモ」の、サポート・利用規約・プライバシーポリシー・特定商取引法の表記のページと、
アプリがダウンロードして使うフォントの置き場所です。GitHub Pages で公開します。

- `index.html` … サポート（よくある質問・お問い合わせ）
- `terms.html` … 利用規約
- `privacy.html` … プライバシーポリシー
- `tokushoho.html` … 特定商取引法に基づく表記（氏名・住所・電話番号は請求があれば開示）
- `fonts/` … アプリのフォント（Google Fonts の公開リポジトリ https://github.com/google/fonts から写したもの。
  すべて SIL Open Font License 1.1。各フォルダの `OFL.txt` がライセンス）

アプリ本体のリポジトリ（非公開・PaperMemo）の `Documents/公開の準備（大槻さんの作業）.md` から管理しています。
内容を変えたときは、ページの「制定日」の横に改定日を書き足してください。
**フォントのファイル名・フォルダ名は変えないこと**（アプリがこの場所から決まった名前で取りに来るため）。
